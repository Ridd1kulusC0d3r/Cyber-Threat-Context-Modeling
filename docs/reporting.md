# Reporting

One assessment should produce different views for different decisions.

| Audience | Primary output |
|---|---|
| Executive / CISO | crown jewels, top scenarios, residual risk, decisions |
| CTI | requirements, evidence, hypotheses, confidence, intelligence gaps |
| Architecture | attack paths, trust boundaries, choke points, controls |
| SOC / Detection | telemetry contracts, detection use cases, correlation, validation gaps |

Do not force every audience to consume the same giant report. The same underlying case data should generate audience-specific views.
