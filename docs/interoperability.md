# Interoperability

TCE is intentionally not a replacement for CTI or threat-informed-defense standards.

| TCE concept | Interoperability direction |
|---|---|
| Threat actor, campaign, malware, infrastructure | STIX 2.1 and ATT&CK where appropriate |
| ATT&CK behavior | ATT&CK identifiers |
| Ordered attack behavior | Attack Flow |
| Defensive technique | D3FEND and local control catalogs |
| Crown jewel | TCE-specific organizational entity |
| Architecture node and trust boundary | TCE-specific organizational entity |
| Intelligence Requirement | TCE-specific analytical entity |
| Telemetry Contract | TCE-specific engineering entity |
| Detection Use Case | TCE-specific defensive entity |
| Validation Evidence | TCE-specific evidence entity |
| Decision Trace | TCE-specific relationship chain |

External identifiers should be stored alongside local identifiers, never replace local context.
