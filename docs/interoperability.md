# Interoperability

TCEM is intentionally not a replacement for CTI or threat-informed-defense standards.

| TCEM concept | Interoperability direction |
|---|---|
| Threat actor, campaign, malware, infrastructure | STIX 2.1 and ATT&CK where appropriate |
| ATT&CK behavior | ATT&CK identifiers |
| Ordered attack behavior | Attack Flow |
| Defensive technique | D3FEND and local control catalogs |
| Crown jewel | TCEM-specific organizational entity |
| Architecture node and trust boundary | TCEM-specific organizational entity |
| Intelligence Requirement | TCEM-specific analytical entity |
| Telemetry Contract | TCEM-specific engineering entity |
| Detection Use Case | TCEM-specific defensive entity |
| Validation Evidence | TCEM-specific evidence entity |
| Decision Trace | TCEM-specific relationship chain |

External identifiers should be stored alongside local identifiers, never replace local context.
