# Coverage Model

TCE does not mark a technique as covered merely because a rule mentions an ATT&CK ID.

Each detection use case tracks telemetry, analytic, correlation, validation, and response coverage. Each dimension uses covered, partial, missing, or unknown.

The practical output is a statement such as: visibility exists, an analytic exists, correlation is incomplete, validation is missing, and response maturity is partial.
